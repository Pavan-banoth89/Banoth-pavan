🌐 Project Overview

This project demonstrates how to host a simple static website for free using GitHub Pages. It includes HTML, CSS, and JavaScript files, showcasing a clean, responsive, and interactive webpage.

Users can learn how to deploy static websites online, manage versions using Git, and make their projects publicly accessible.

🎯 Objective

Host a static website on GitHub Pages for free.

Understand version control and deployment workflow.

Learn to update and maintain live websites using Git and GitHub.

🧰 Tools Used

GitHub Account – for hosting and repository creation

Git CLI or GitHub Desktop – for committing and pushing changes

VS Code / Code Editor – to edit and manage website files

Browser – to view and test the live website
